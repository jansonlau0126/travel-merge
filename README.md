# 環遊合併 — Prototype

載具進化幻想 + 世界著名景點（簡單→宏偉）嘅可玩合併遊戲原型。

## 點樣開

**方法 A（最簡單）**  
用瀏覽器直接打開 `index.html`（雙擊，或拖入 Chrome / Edge / Firefox）。`file://` 可以玩。

**方法 B（本機靜態伺服器）**
```bash
cd /workspace/merge-game/prototype
python3 -m http.server 8080
```
然後開瀏覽器去 `http://localhost:8080/`。

唔使 build、唔使安裝依賴。

## 點玩

1. 撳 **零件堆**（耗 1 ⚡）產出滑板／偶有單車。
2. **兩個相同等級**拖埋一齊，或者先點一個再點另一個 → 合併成下一階載具。  
   鏈：滑板 → 單車 → 電動滑板車 → 電單車 → 二手私家車 → 廂型車 → 長途巴士 → 列車 → 渡輪 → 客機。
3. 滿足訂單需求後撳 **交單**，賺 **旅費**。
4. 旅費夠就解鎖下一個景點；解鎖埃菲爾鐵塔後完成 **鐵塔首航**（客機×1）＝第一章勝利。
5. 試玩能量唔夠可撳 **+10 ⚡**；開住頁面會每 30 秒自動 +1 能量。
