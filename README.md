# 環遊合併（Travel Merge）

可玩網頁 prototype：**載具進化幻想** + 世界著名景點進度。

玩法受市場頭部 merge（如 Gossip Harbor 類）啟發：暖色休閒 UI、能量再生、旅客訂單卡、x2 渦輪；主題與資產皆原創，唔係任何商業遊戲嘅 clone。

## 玩

https://jansonlau0126.github.io/travel-merge/

本地：開 `index.html` 即可。

## 操作

- 撳「零件堆」耗能量產出載具零件
- 兩個相同載具拖埋／點兩下合併
- 交旅客訂單賺旅費，解鎖景點印章
- **x2 渦輪**：開咗耗 2⚡，出更高階
- `+10` 為試玩加能量
