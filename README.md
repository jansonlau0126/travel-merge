# 環遊合併（Travel Merge）Prototype

載具進化幻想 · 由簡陋代步行遍世界著名景點。

玩法：撳生產器耗能量出載具 → 合併升級 → 交旅客訂單賺旅費 → 解鎖景點 → 客機鐵塔首航過關。

## 生產器（多掉落表）

| 生產器 | 解鎖 | 平常掉落 | 渦輪掉落 |
|--------|------|----------|----------|
| 零件堆 | 開局 | Lv1–2 | Lv2–3 |
| 修車鋪 | 開局 | Lv2–4 | Lv3–5 |
| 行李倉 | 大笨鐘 | Lv4–6 | Lv5–7 |

棋盤底部同浮掣都可以撳。

## 訂單節奏

- 固定 4 單：1 易 + 2 中 + 1 難
- 易單偏向當前生產器可及等級（一局內可交）
- 中／難同易單需求有重疊，進度 60%+ 顯示「就差少少」
- 其中一單有限時加成（約 3 分鐘 +50% 旅費）

## Layout DNA（P0–P6）

- 頂 HUD（能量倒數）→ 顧客頭頂訂單泡 → 木棋盤主導 → 底詳情條
- 生產器／渦輪浮喺棋盤邊
- 原創 SVG 載具＋顧客；glossy CSS 棋子
- 比例：HUD ~7.5% / 顧客 ~14.5% / 棋盤 ~68% / 詳情 ~10%

GitHub Pages：https://jansonlau0126.github.io/travel-merge/


## 景點裝修 meta
- 用旅費解鎖下一站景點（扣旅費）
- 用旅費裝修當前景點：畫面 before（灰）→ after（亮）
- 撳頂右「裝修」或景點列開啟面板

## 音效同粒子
- Web Audio 嗶聲（合併／交單／解鎖），唔使外部音檔
- 合併同交單會噴粒子；頂欄有 🔊／🔇 靜音掣（記住偏好）

## 第一章平衡（早期爽感）
- 景點解鎖：鳥居 50 → 斜塔 120 → 大笨鐘 250 → 自由女神 450 → 鐵塔 700
- 訂單旅費抬高；交單另回饋 2／3／5 ⚡
- 能量再生 1.5 分鐘 +1；開局多兩件起步載具
- 仍維持同時 1 易 + 2 中 + 1 難
