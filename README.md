# 環遊合併（Travel Merge）Prototype

載具進化幻想 · 由簡陋代步行遍世界著名景點。

玩法：撳生產器耗能量出載具 → 合併升級 → 交旅客訂單賺旅費 → 解鎖景點 → 客機鐵塔首航過關。

## 生產器（多掉落表）

| 生產器 | 解鎖 | 平常掉落 | 渦輪掉落 |
|--------|------|----------|----------|
| 零件堆 | 開局 | Lv1–2 | Lv2–3 |
| 修車鋪 | 開局 | Lv2–4 | Lv3–5 |
| 行李倉 | 大笨鐘 | Lv4–6 | Lv5–7 |

棋盤底部同浮掣都可以撳。

## 訂單節奏

- 固定 4 單：1 易 + 2 中 + 1 難
- 易單偏向當前生產器可及等級（一局內可交）
- 中／難同易單需求有重疊，進度 60%+ 顯示「就差少少」
- 其中一單有限時加成（約 3 分鐘 +50% 旅費）

## Layout DNA（P0–P6）

- 頂 HUD（能量倒數）→ 顧客頭頂訂單泡 → 木棋盤主導 → 底詳情條
- 生產器／渦輪浮喺棋盤邊
- 原創 SVG 載具＋顧客；glossy CSS 棋子
- 比例：HUD ~7.5% / 顧客 ~14.5% / 棋盤 ~68% / 詳情 ~10%
