# 環遊合併 — 載具進化幻想

可玩網頁 prototype（Travel Town / Gossip Harbor **版面 DNA**）。

## 玩法
- 撳左下 **零件堆** 耗能量出滑板
- 兩個相同載具合併升級
- 撳顧客交單（頭頂泡顯示需要嘅載具）
- 旅費解鎖景點 → 客機「鐵塔首航」過關
- 右下 **渦輪** = 耗雙倍能量、更高階掉落

## Layout（P0+P1）
| 層 | 約佔高 | 內容 |
|---|---|---|
| 頂 HUD | ~8% | 等級、能量+倒數、旅費、寶石、店 |
| 景點條 | ~3.5% | 迷你印章進度 |
| 顧客列 | ~15% | 橫排角色 + **頭頂訂單泡** |
| 木棋盤 | ~63% | 7×8 主導畫面 |
| 底欄 | ~10% | 零件堆 / 詳情 / 渦輪 |
