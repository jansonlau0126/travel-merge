# 環遊合併（Travel Merge）Prototype

載具進化幻想 · 由簡陋代步行遍世界著名景點。

玩法：撳零件堆耗能量出滑板 → 合併升級 → 交旅客訂單賺旅費 → 解鎖景點 → 客機鐵塔首航過關。

## Layout DNA（對標 merge 爆款結構，原創主題／美術）

- 頂 HUD（能量倒數）→ 顧客頭頂訂單泡 → 木棋盤主導 → **收合詳情條**
- 零件堆／渦輪浮喺棋盤邊（唔搶底欄）
- 選中棋子先展開詳情（名／下一階／用途）
- 原創 SVG 載具＋顧客 bust；glossy CSS 棋子
